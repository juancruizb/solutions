Implementación OAuth + SDP Solutions API
Completado
OAuth Manager — resources/token/sdp_auth.py
Método Descripción
get_access_token(client_id, secret) Punto de entrada. Devuelve token válido y refresca si expiró
refresh_access_token(...) Llama a Zoho OAuth y obtiene nuevo access_token
save_tokens(data) Persiste tokens en token_store.json
load_tokens() Lee tokens almacenados localmente
SDP API Client — resources/solutions/sdp_solutions.py

Replica exacta de los calls configurados en Postman.

Método Descripción
get_all(token, start_index=0, row_count=1000) Un lote de soluciones con offset
get_all_paginated(token) Pagina automáticamente y retorna TODAS las soluciones
get_by_id(token, solution_id) Detalle de una solución específica
Headers (idénticos a Postman)
Authorization: Zoho-oauthtoken {token}
Accept: application/vnd.manageengine.sdp.v3+json
Content-Type: application/x-www-form-urlencoded
